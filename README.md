### `$ whoami`

Software engineer with a systems-level mindset. I enjoy going deep — whether that means reverse-engineering an API protocol, writing firmware for a microcontroller, or architecting a real-time monitoring platform from scratch.

My work spans **IoT & embedded systems**, **full-stack web platforms**, **automation & browser engineering**, **reverse engineering & protocol analysis**, and **real-time data infrastructure**. I care about understanding how things work under the hood, and building software that reflects that understanding.

---

### What I Build

🔩 **Systems that bridge hardware and software** — ESP32 sensor networks, MQTT pipelines, automated irrigation, real-time device monitoring

🌐 **Full-stack platforms** — Marketplace systems with payment integration, monitoring dashboards with live analytics, modular admin panels

🔬 **Tools that go beneath the surface** — Protocol analysis, TLS fingerprinting, API reverse engineering, device simulation, cryptographic implementations

⚙️ **Automation infrastructure** — Browser automation, proxy orchestration, batch processing, headless workflows at scale

🛠️ **Developer tools & open source** — Terminal-based system monitors, regex engines, browser extensions, REST API toolkits, clean code guides

🖥️ **Server infrastructure** — Windows & Linux administration, security hardening, performance optimization, deployment pipelines
